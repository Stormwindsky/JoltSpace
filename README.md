# JoltSpace
JoltSpace is a ViolentMonkey script, i.e., a userscript for customizing your Gamejolt profile like SpaceHey.


here how to custom your profile on Gamejolt

first copy paste the .js script to the extension / addon on violentmonkey

& after use this link & add the links you want

here: https://www.stormwindsky.com/Tools/Notepad/Notepad.html#cursor%20%3D%20URL%20HERE%0A%0Amusic.play%20%3D%20URL%20HERE%0A%0Apfp%20%3D%20URL%20HERE

& after put all links copy the url with the button: (Save as URL)

& after paste the url to your profile from your Profile Bio & save that

& voila :)
